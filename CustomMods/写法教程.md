# `.cw.json` 写法教程（玩家版 · 参照自定义难度 JSON 写法）

> CustomMods 武器自定义配置写法指南 v1（2026-10-04）
> 对照阅读：难度的写法看 Koncin 的《自定义难度代码 HazardX 注释版》（`资料\难度JSON\`），本文按同样的方式讲武器。
> **总原则：不写 = 原版。写了的才改，没写的保持原样。**

---

## 一、文件放哪、怎么生效

1. 新建文本文件，改名成 `你想叫的名字.cw.json`（UTF-8 编码）
2. 按下面各节写内容
3. 运行生成器出 pak：`python CustomMods\tools\cmgen.py 你的配置.cw.json`
4. 把产出的 pak 装进游戏（mod.io / mintcat / 手动挂载，见安装节）
5. **同一房间的所有玩家要装同一份配置**（和自定义难度同理——数值必须一致）

## 二、骨架（全字段注释版）

```jsonc
{
  "FormatVersion": 1,              // 格式版本，目前必须是 1
  "Name": "我的武器调整",            // 配置名（必填），也是产出 pak 的文件名
  "Description": "随便写点说明",      // 可选
  "Author": "你的ID",               // 建议与 GitHub/mod.io 一致，方便合集署名

  "Overrides": {                    // ┓ 第一节：改"现有"超频的数值
    "资产名": { ... }                // ┃ 写法见第三节
  },                                // ┛

  "CustomOverclocks": [             // ┓ 第二节：创建"全新"超频
    { ... }                         // ┃ 写法见第四节
  ]                                 // ┛
}
```

两节都是可选的。什么都不写（两个都空）= 纯原版配置（见示例 `00-vanilla-default.cw.json`）。

## 三、Overrides：改现有超频的数值

**先查目录**：打开 `data\weapon_overclock_catalog.md`（速查表），找到你想改的超频。
目录里一行 = 一个可改的"元素"，抄它的资产名当键。

```jsonc
"Overrides": {
  "OC_Bonus_RoF+3_AssaultRifle": {     // 元素资产名（从目录抄，一字不差）
    "Weapon": "AssaultRifle",          // 武器目录名（校验用，从目录抄）
    "Set": {
      "Amount": 6.0,                   // 数值本体。目录里 Amount = 3 就是原版值，改成你想要的数
      "UpgradeType": "RateOfFire"      // 可选：连"是什么属性"也能换（合法值见枚举表）
    }
  }
}
```

### 怎么读懂目录的一行

```
- OC_AssaultRifle_RoF_B（Balanced）
  - `OC_Bonus_RoF+3_AssaultRifle`: RateOfFire = 3.0     ← 加成：射速 +3
  - `OC_Penalty_Recoil_AssaultRifle`: RecoilMultiplier = 1.0 ← 惩罚：后坐力 ×1
```

- 括号里的 Balanced = 品质（无瑕 Clean / 均衡 Balanced / 不稳定 Unstable）
- 每行 `资产名: 属性 = 原版值`——**改的就是那个数**。想射速 +6 就写 `"Amount": 6.0`；
  想把惩罚变成增益就写负数（如后坐力写 `-0.3`）

### 数值语义三句话

1. **加值型**（Damage、RateOfFire、MaxAmmo…）：正数 = 加多少
2. **乘区型**（RecoilMultiplier、各种 Resistance…）：数字是倍率/修正，原版参照目录值
3. **拿不准就抄目录原值再改**——原值就是最好的格式示例（填离谱大数会被校验拦下，和难度 JSON 的 999 坑同理）

## 四、CustomOverclocks：创建全新超频

v1 用「重铸槽位」方式：挑一个现有超频的位置，把它彻底重做成你设计的数值（名字/文本仍是原槽位的，改名能力 v1.1）。

```jsonc
"CustomOverclocks": [
  {
    "Id": "MyFirst_OC",                    // 内部 ID（随便起，英文）
    "Weapon": "AssaultRifle",              // 归属武器（决定放哪个武器的锻造台）
    "Quality": "Balanced",                 // Clean / Balanced / Unstable 三选一
    "Name": "稳如老狗",                     // 备忘用（v1 不改游戏内显示名）
    "Description": "射速小涨后坐力大降",
    "StatTexts": ["+4 射速", "-30% 后坐力"], // 备忘用
    "Elements": [                          // 数值本体：按顺序填，每条 = 重铸一个元素槽
      { "Class": "AmmoDrivenWeaponUpgrade", "UpgradeType": "RateOfFire",       "Amount": 4.0 },
      { "Class": "AmmoDrivenWeaponUpgrade", "UpgradeType": "RecoilMultiplier", "Amount": -0.3 }
    ],
    "Replace": "OC_AssaultRifle_RoF_B"     // 被重铸的超频资产名（从目录抄）
  }
]
```

规则：`Elements` 条数 ≤ 被重铸超频的元素数（目录里数一下）；顺序一一对应。

## 五、合法属性名速查（UpgradeType）

完整表：`data\upgrade_enums.json`（55 组 / 318 个值）。常用的：

| 属性 | 意思 | | 属性 | 意思 |
|---|---|---|---|---|
| MaxAmmo | 备弹 | | Damage | 直伤 |
| ClipSize | 弹匣 | | WeakpointDamageMultiplier | 弱点倍率 |
| RateOfFire | 射速 | | StaggerChance | 眩晕几率 |
| ReloadSpeed | 装填 | | RadialDamage / RadialRange | AOE 伤害/半径 |
| RecoilMultiplier | 后坐力 | | ArmorPenetration | 穿甲 |

## 六、坑列表（对应难度教程的"另外"节）

1. **写了和原版一样的值 = 自动跳过**（不产补丁、不报错），想生效必须真的改数
2. 资产名必须和目录**一字不差**（含 `+` `-` 等符号），错一个字符直接拒产
3. `UpgradeType` 必须是枚举表里的合法值，乱写会被校验拦下
4. 生成器任何一步校验失败 = **整包不产出**（宁可不出，不出半成品）
5. 官方更新后资产可能变化——生成器每次从你的游戏 pak 现读现做，游戏更新后重跑一遍即可
6. 多人房间：所有玩家同一份 pak，否则数值不一致
7. 和难度 JSON 的分工：**难度/生物改 `.cd.json`（CH 已有），武器/超频改 `.cw.json`（本系统）**，两边可以同时用、互不干扰

## 七、一条龙示例

写好配置 → 出 pak → 校验清单：

```
python CustomMods\tools\cmgen.py 我的配置.cw.json --dry-run   ← 先看计划（会列出改哪些资产）
python CustomMods\tools\cmgen.py 我的配置.cw.json             ← 正式产出 pak
```

产出报告里每条补丁都有 `OldValue → NewValue` 对照，确认无误再装。
示例配置见 `examples\`（00 原版 / 10 改数值 / 20 新建超频）。
